📌 Project Overview
Bank Lending Analytics is an exploratory data analysis project designed to transform raw loan-level data into meaningful business, customer, portfolio, and credit-risk insights.
The project examines how lending activity changes over time, how customers borrow across different segments, how loans perform across grades and purposes, and where potential risk patterns can be observed.
This approach helps convert complex lending data into information that can support portfolio monitoring, customer analysis, lending strategy, and risk assessment.

Rather than focusing only on charts, the analysis follows an insight-driven workflow:

<p align="center">
  <strong>Raw Data → Clean & Validate → Feature Engineering → Exploratory Analysis → Visualization → Business Insights</strong>
</p>
